What is a JSON formatter?

A JSON formatter takes raw or minified JSON and rewrites it with proper indentation so it's easier to read. It also validates the JSON, telling you if there's a syntax error and where it is.

How to use it

  1. Paste your JSON into the Input box.
  2. Click Format to beautify it.
  3. Click Minify to strip all whitespace.
  4. Click Copy to copy the result.

Privacy

This tool runs entirely in your browser using JSON.parse() and JSON.stringify(). Nothing you paste is sent to a server.

What is Base64?

Base64 is a way of encoding binary data as text using 64 characters (A–Z, a–z, 0–9, +, /). It's commonly used to embed images in HTML, transmit data in JSON, and encode credentials in HTTP headers.

How to use it

  1. Type or paste text into the Input box.
  2. Click Encode to convert text to Base64.
  3. Or paste Base64 and click Decode.
  4. Click Copy to copy the result.

Privacy

This tool uses JavaScript's built-in btoa() and atob(). Nothing is sent to a server.

Image Compressor

Compress JPG and PNG images in your browser. Your files never leave your device.

What is an image compressor?

An image compressor reduces the file size of an image while keeping it visually similar. Smaller images load faster and are easier to share.

How to use it

  1. Click the drop zone or drag your images into it.
  2. Adjust the quality slider.
  3. Click Compress.
  4. Download each compressed image.

Privacy

This tool uses the HTML5 Canvas API to re-encode your images entirely inside your browser. Your files are never uploaded anywhere.
